# 🛒 Marketplace - E-Commerce Platform

A full-featured marketplace web application built with Django, allowing users to list products, browse categories, and communicate with sellers through an integrated messaging system.

## ✨ Features

### Core Features
- **User Authentication**: Secure registration, login, and logout system
- **Product Management**: Full CRUD operations for product listings
- **Category System**: Organize products by categories for easy browsing
- **Image Upload**: Upload product images with Django's ImageField
- **Personal Dashboard**: Manage your own product listings
- **Real-time Messaging**: Chat system between buyers and sellers
- **Sold Status Tracking**: Mark products as sold when transactions complete

### User Features
- Create product listings with title, description, price, and images
- Browse products by category
- Search and filter products
- View detailed product information
- Start conversations with sellers about specific products
- Inbox system to manage all conversations
- Edit or delete your own product listings

## 🛠️ Tech Stack

### Backend
- **Framework**: Django 4.x (Python)
- **Database**: SQLite (default)
- **ORM**: Django ORM
- **Authentication**: Django built-in auth system
- **Image Processing**: Pillow (for ImageField)

### Frontend
- **Templating**: Django Templates
- **Styling**: HTML/CSS
- **JavaScript**: Vanilla JS (for interactive features)
